# MERN Collage Event Management Website

A online platform for managing collage events

## Feature

    - Authentication (Clerk)
    - Admin Dashboard
    - Organizer Dashboard
    - Student Dashboard
    - ongoinig

## Tech stack

    - React : Frontend
    - Typescript : JS types
    - Express : Backend
    - Postgress : Database
    - Node.js
    - Cloudinary : Image upload
    - shadcn : for design

## Installation

    - clone the project
        - git clone https://github.com/Codeer-man/Collage_event_management.git

    - client
        - cd client
        - npm install
        - ongoinng

    - server
        - cd server
        -npm install
        - on going

## Environment variables

    -- Backend
        - PORT=
        - CORS_ORIGIN="http://localhost:5173"

## How to run the project

    - client
        - npm run dev

    - server
        - npm run dev
